# AI-DLC Estágio 2.7 - Plano de Entrega e Portões de Verificação

## Fases e Marcos de Execução (AI-DLC Construction)

### Sprint 1: Fundação do Backend e Persistência (UoW-01 a UoW-03)
* Setup do projeto Node.js + TypeScript com TypeORM e Zod.
* Entidades mapeadas e sincronizadas.
* Algoritmos de cálculo obstétrico (Regra de Naegele e Idade Gestacional) validados por testes unitários.
* **Gate 1:** Entidades compilando e testes de cálculos obstétricos passando com 100% de sucesso.

### Sprint 2: Regras de Negócio e Inteligência C3 / Alertas (UoW-04 a UoW-07)
* Serviços de cadastro de Profissional, Paciente, Bebê e Vacinas com exclusão condicional.
* Serviços de movimentações clínicas (Visitas, Consultas, Vacinas, Odonto).
* Implementação do motor de pontuação da Nota C3 (11 boas práticas).
* Implementação da agenda de alertas preditivos para busca ativa do ACS.
* **Gate 2:** Testes unitários e de integração do motor C3 e alertas passando.

### Sprint 3: API REST, Servidor e Testes E2E (UoW-08 e UoW-09)
* Endpoints REST montados e validados com middleware de erro e Zod.
* Dados semente (seeds) com casos clínicos realistas (ex: gestante de baixo risco em dia, gestante com visita atrasada, puérpera precisando de visita).
* **Gate 3:** API REST respondendo a todas as rotas com conformidade aos contratos.

### Sprint 4: Frontend SPA e Experiência do Usuário (UoW-10)
* Interface React + Vite + TailwindCSS conectada à API REST.
* Painel de Alertas de Ação Imediata do ACS.
* Calculadora visual interativa da Nota C3.
* Prontuário ágil de cadastro de visitas e consultas.
* **Gate 4:** Build de produção bem-sucedido e aplicação ponta a ponta validada.
