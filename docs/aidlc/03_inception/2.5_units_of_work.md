# AI-DLC Estágio 2.5 - Decomposição em Unidades de Trabalho (Units of Work)

| Unidade de Trabalho (UoW) | Componente / Responsabilidade | Prioridade | Dependências |
| :--- | :--- | :---: | :--- |
| **UoW-01: Setup & Entidades** | Configuração do TypeORM, DataSource e Entidades com relacionamentos | Alta | Nenhuma |
| **UoW-02: Validações & Schemas** | Schemas Zod (validação de CPF, datas, tipos numéricos) | Alta | UoW-01 |
| **UoW-03: Motor Obstétrico** | Módulo `CalculosObstetricos` (DPP, idade gestacional em semanas) | Alta | Nenhuma |
| **UoW-04: Cadastros Essenciais** | Controllers e Services para Profissional, Paciente, Bebê, Vacina | Alta | UoW-01, 02, 03 |
| **UoW-05: Movimentações Clínicas** | Controllers e Services de Visita, Consulta, Vacinação, Odonto | Alta | UoW-04 |
| **UoW-06: Motor da Nota C3** | Módulo `CalculadoraC3Service` (11 boas práticas oficiais da Nota C3) | Crítica | UoW-03, 05 |
| **UoW-07: Motor de Alertas** | Módulo `AlertasPendenciasService` (visitas atrasadas, puerpério, vacinas) | Crítica | UoW-03, 05 |
| **UoW-08: Rotas e Servidor REST** | Integração dos endpoints REST no Express e tratamento de erros | Alta | UoW-04 a 07 |
| **UoW-09: Suíte de Testes Automatizados** | Testes de unidade, cálculo obstétrico, motor C3 e endpoints | Alta | UoW-03 a 08 |
| **UoW-10: Frontend SPA** | Interface React + TailwindCSS (Dashboard C3, Agenda Alertas, Prontuário) | Alta | UoW-08 |
