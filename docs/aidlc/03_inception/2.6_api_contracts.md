# AI-DLC Estágio 2.6 - Contratos de API (Endpoints & Payloads)

## 1. Profissionais
* `POST /api/profissionais`
  * Body: `{ nome: string, cpf: string, funcao: "ACS" | "MEDICO" | "ENFERMEIRO" | "DENTISTA" }`
  * Resposta: `201 Created` ou `400 Bad Request` (duplicação de CPF ou formato inválido)
* `GET /api/profissionais`
  * Query: `?funcao=ACS`
  * Resposta: `200 OK` (Array de Profissionais)

## 2. Pacientes
* `POST /api/pacientes`
  * Body: `{ nome: string, cpf: string, dataNascimento: string, dum: string, profissionalId: string }`
  * Regra: Calcula automaticamente `dpp` e define `status = "GESTANTE"`.
* `GET /api/pacientes`
  * Query: `?busca=Maria&status=GESTANTE`
  * Resposta: Lista de pacientes com DPP, IG atual e profissional vinculado.
* `GET /api/pacientes/:id`
  * Resposta: Detalhes completos, bebê (se houver), histórico de consultas, visitas, vacinas e odonto.
* `PUT /api/pacientes/:id/parto`
  * Body: `{ dataParto: string, bebe?: { nome: string, sexo: "M" | "F", pesoNascimentoGramas: number } }`
  * Regra: Atualiza paciente para `status = "PUERPERA"` e registra o nascimento do bebê.
* `DELETE /api/pacientes/:id`
  * Regra: Exclusão Condicional. Retorna `409 Conflict` se houver qualquer movimentação associada.

## 3. Movimentações Clínicas
* `POST /api/movimentacoes/visitas`
  * Body: `{ pacienteId: string, profissionalId: string, dataVisita: string, fase: "GESTANTE" | "PUERPERA", observacoes?: string }`
* `POST /api/movimentacoes/consultas`
  * Body: `{ pacienteId: string, profissionalId: string, dataConsulta: string, pressaoArterial: string, pesoKg: number, alturaCm: number, fase: "GESTANTE" | "PUERPERA" }`
* `POST /api/movimentacoes/vacinacoes`
  * Body: `{ pacienteId: string, vacinaNomeTipo: string, dataAplicacao: string, dose: number }`
* `POST /api/movimentacoes/odonto`
  * Body: `{ pacienteId: string, profissionalId: string, dataAvaliacao: string, observacoes?: string }`

## 4. Inteligência e Alertas
* `GET /api/inteligencia/indicadores/:pacienteId`
  * Resposta: `{ pontuacaoTotal: number, boasPraticas: [ { id: "A", nome: string, pontos: number, cumprida: boolean, detalhes: string } ] }`
* `GET /api/inteligencia/alertas`
  * Resposta: `{ totalAlertas: number, visitasAtrasadasGestacao: [], visitasAtrasadasPuerperio: [], vacinasPendentes: [] }`
