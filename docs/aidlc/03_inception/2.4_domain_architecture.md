# AI-DLC Estágio 2.4 - Modelo de Domínio e Arquitetura do Sistema

## 1. Arquitetura em Três Camadas
```
┌────────────────────────────────────────────────────────┐
│               Camada de Apresentação                   │
│           (React + TypeScript + TailwindCSS)           │
│   • Dashboard Nota C3 • Agenda Alertas • Prontuário   │
└───────────────────────────┬────────────────────────────┘
                            │ HTTP / JSON
┌───────────────────────────▼────────────────────────────┐
│                Camada de Aplicação                     │
│               (Node.js + Express REST)                 │
│  ├── Middleware de Validação Zod & Regras CPF          │
│  ├── Módulo de Cadastros (Profissional, Paciente, Bebê)│
│  ├── Módulo de Movimentações (Visita, Consulta, etc.)  │
│  └── Motor de Inteligência:                            │
│       • CalculosObstetricos (Naegele, Semanas IG)      │
│       • CalculadoraC3Service (11 Boas Práticas C3)     │
│       • AlertasPendenciasService (Busca Ativa)         │
└───────────────────────────┬────────────────────────────┘
                            │ TypeORM Data Mapper
┌───────────────────────────▼────────────────────────────┐
│                Camada de Persistência                  │
│       (PostgreSQL / SQLite DataSource Transacional)    │
│  8 Tabelas: profissionais, pacientes, bebes, vacinas,   │
│             visitas, consultas, vacinacoes, odonto     │
└────────────────────────────────────────────────────────┘
```

## 2. Diagrama de Classes e Entidades de Domínio
* **Profissional:** `id`, `nome`, `cpf`, `funcao` (ACS, MEDICO, ENFERMEIRO, DENTISTA)
* **Paciente:** `id`, `nome`, `cpf`, `dataNascimento`, `dum`, `dpp`, `dataParto`, `status` (GESTANTE, PUERPERA, FINALIZADA), `profissionalId`
* **Bebe:** `id`, `pacienteId`, `nome`, `dataNascimento`, `sexo`, `pesoNascimentoGramas`
* **Visita:** `id`, `pacienteId`, `profissionalId`, `dataVisita`, `fase`, `observacoes`
* **Consulta:** `id`, `pacienteId`, `profissionalId`, `dataConsulta`, `pressaoArterial`, `pesoKg`, `alturaCm`, `idadeGestacionalSemanas`, `fase`
* **Vacinacao:** `id`, `pacienteId`, `vacinaNomeTipo`, `dataAplicacao`, `dose`, `idadeGestacionalSemanas`
* **AvaliacaoOdontologica:** `id`, `pacienteId`, `profissionalId`, `dataAvaliacao`, `observacoes`
* **Vacina:** `id`, `nomeVacinaTipo`
