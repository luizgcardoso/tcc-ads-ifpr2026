# AI-DLC Estágio 1.3 - Análise de Viabilidade e Restrições Técnicas

## 1. Viabilidade Técnica
* **Tecnologias Selecionadas:** Node.js + TypeScript para o backend (tipagem estática forte, ecossistema rico e performance ágil), Zod para validação rigorosa de schemas e regras como validação de CPF matemático, TypeORM para mapeamento objeto-relacional resiliente com migrações, e React com TailwindCSS para interface web de alta responsividade.
* **Viabilidade de Execução:** Suporte tanto a PostgreSQL quanto a SQLite embedded para facilitar desenvolvimento, testes automatizados e implantação sem fricção.
* **Complexidade Algorítmica:** Baixa latência nos cálculos obstétricos (cálculo de DPP por Regra de Naegele e Idade Gestacional em semanas baseado em DUM e datas de eventos).

## 2. Restrições Identificadas
1. **Ambiente do ACS em campo:** Os agentes costumam utilizar celulares ou computadores compartilhados da UBS; logo, a interface não pode ter sobrecarga de dependências pesadas no cliente e deve ser totalmente responsiva.
2. **Integridade de Dados Clínicos:** Não é permitida a exclusão física de pacientes que possuam qualquer histórico médico ou movimentação clínica vinculada.
3. **Privacidade e LGPD:** O sistema lida com dados sensíveis de saúde da mulher e da criança. É obrigatória a validação estrita de dados e proteção contra injeções.
